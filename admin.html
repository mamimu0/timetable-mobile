GitHub連携(自動公開)

未設定です。設定すると、下の「公開する」を押すだけでGitHubに反映されます。

設定する
  1. GitHubのトークン発行ページを開く
  2. Repository access を「Only select repositories」にし、timetable-mobile を選ぶ
  3. Permissions → Repository permissions → Contents を Read and write にする
  4. 有効期限を選ぶ(90日など。GitHubの実際の期限日はこの後の画面か、発行済みトークン一覧で確認できます)。「Generate token」を押す
  5. 表示されたトークン(github_pat_...)をコピーして、下に貼り付けて保存。有効期限の日付も、GitHubで選んだ通りに入力してください(このページに表示するためのメモで、GitHub側の実際の期限とは別管理です)

このトークンはこのブラウザだけに保存され、サイトのコードには含まれません。誰にも見せず、他の端末では使わないでください。不要になったらGitHub側でいつでも失効できます。

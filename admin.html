GitHubへのアップロード手順

  1. 書き出された weeks.json を、リポジトリの data フォルダを開いて「Add file → Upload files」でドラッグし、Commit。
  2. 書き出された g*.ics ファイルたちを、ics フォルダを開いて同じようにまとめてドラッグし、Commit。
  3. 数十秒〜1分待つと、サイト(index.html)に反映されます。

フォルダが無ければ、Upload files の画面でファイル名の先頭に data/weeks.json のようにパスごと入力してドラッグすると、自動でフォルダが作られます。
